# Note App

## Overview

The **Note Display App** is a simple and interactive web application designed to help users take, edit, delete, and display notes in an organized manner. The app features a visually appealing UI and allows users to store their thoughts in one place.

## Features

- **Add Notes**: Users can create new notes by clicking the `+` button.
- **Edit Notes**: Existing notes can be edited.
- **Delete Notes**: Unwanted notes can be removed.
- **Share Notes**: Users have the option to share notes.
- **Beautiful UI**: Includes dynamic overlays and animations for a smooth user experience.
- **Responsive Design**: Optimized for various screen sizes.
- local storage support to save notes persistently.

## How to Use

1. Open the `index.html` file in a browser.
2. Click the `+` button to create a new note.
3. Type in a title and note content.
4. Click **Save note** to store it.
5. Click on a note to view details.
6. Double click a specific note to show multiple options such as: delete, edit, and share.
